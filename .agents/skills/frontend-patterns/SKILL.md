# Frontend patterns
Follow existing React component/state conventions. Avoid redundant state and needless rerenders. Keep socket subscriptions paired with teardown; verify stale closures, error/loading/empty states and mobile responsiveness. Never expose private game state to a shared TV view. Test interactions using existing tests. Do not introduce telemetry or new packages without approval. Upstream: https://github.com/affaan-m/ECC/tree/main/.agents/skills/frontend-patterns
