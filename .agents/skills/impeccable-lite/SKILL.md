# Impeccable-lite — UI refinement
For UI changes, inspect existing design and preserve product behavior. Optimize phone controls for quick touch, TV readouts for distance, clarity of game phases, contrast, focus indicators, status/error/empty/loading states, motion reduction and varied screen sizes. Distinguish improvement from unrequested redesign. Validate actual rendered views where tools are available; never claim visual verification without screenshots or browser checks. This is a project-safe adaptation, NOT the full upstream skill, whose launcher can download binaries. Upstream: https://github.com/pbakaus/impeccable
