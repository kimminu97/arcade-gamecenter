# Smallest complete change
Before coding inspect the relevant files, callers and tests. Reuse local functions and existing dependencies; do not add gratuitous abstraction or optional features. Preserve checks, validation, accessibility and error handling. Add a focused regression test for new nontrivial logic. Explain changes and explicitly state unverified risks. Upstream: https://github.com/DietrichGebert/ponytail/tree/main/skills/ponytail
